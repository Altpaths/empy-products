# Surprise — EMPY

یک تجربه‌ی تعاملی کوتاه و مستقل برای بخش «ایده‌های کاربردی» در EMPY.

## اجرا

فایل `index.html` را مستقیماً در مرورگر باز کنید. این محصول به اینترنت، کتابخانه یا سرویس خارجی وابسته نیست.

## وضعیت نسخه

این نسخه‌ی مستقل بر اساس محتوای قابل مشاهده‌ی لینک اولیه ساخته شده است؛ منبع اصلی `yek-raz.raha-sh91.chatgpt.site` در زمان بسته‌بندی به‌دلیل محافظت Cloudflare قابل دریافت نبود. اگر Export یا سورس اصلی در دسترس قرار بگیرد، می‌توان آن را با همین بسته جایگزین کرد.
