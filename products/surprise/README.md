# Surprise — EMPY

نسخه‌ی اصلی و مستقل محصول Surprise از EMPY.

## اجرا

فایل `index.html` را مستقیماً در مرورگر باز کنید. محصول به اینترنت، کتابخانه یا سرویس خارجی وابسته نیست.

دکمه‌ی «خیر» عمداً غیرفعال است و تنها دکمه‌ی قابل انتخاب «بله» است. پس از نمایش پیام، صفحه بدون دکمه‌ی خروج باقی می‌ماند تا سورپرایز کامل شود.
